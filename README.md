2. Funcionamiento del programa: 

El programa permite registrar usuarios validando la información ingresada y manejando adecuadamente las excepciones.

El programa presenta un menú con dos opciones: 1. registrar usuario y 2. salir. El usuario debe elegir una opción y digitar el número correspondiente para continuar.

Si el usuario digita una opción inválida (Por ejemplo, el nombre de la opción o una letra), el programa mostrara un mensaje de error y solicitará digitar una nueva opción válida.

Al momento de registrar un usuario, se validan distintos criterios. Entre estos que la edad sea un número entre 18 y 100, que el nombre no este vacío o que contenga menos de tres caracteres, que el e-mail del usuario incluya los caracteres "@" y "." y, finalmente, que el salario sea un monto mayor que cero. 

En caso de que alguno de los datos sea inválido, el programa lanzará la excepción correspondiente e informará al usuario cuál fue el error a traves de un mensaje.
